# 算法工具集

本目录汇总四个工具的代码副本：byte、TTSDC、seccom-tee、PQCP。原始项目仍位于 `../modules/`，两份代码不会自动同步。使用前请核对版本与项目内说明。

- byte：安全推理协议；Linux、SGX SDK 等依赖。
- TTSDC：多场景隐私计算；不同模块依赖不同。
- seccom-tee：SGX 和 TrustZone 模块；SGX/RMT_V 位于该副本中。
- PQCP：后量子密码 provider；依赖 openHiTLS 与编译环境。

本目录只做代码归档，不代表上述工具已运行或验证。参考根目录 modules 中的原项目 README。
