# 项目指标与演示设计

保留四个项目各自的菜单、结果和环境；结果页与回放共用同一组项目指标。数据缺失时显示“未记录”，不生成示例数字。演示中的流动连线和小树是讲解动画，不能作为实际报文计时或导出的模型结构。

| 项目 | 主要指标 | 取值依据 | 专属演示 |
| --- | --- | --- | --- |
| SGBoost | 评估准确率、较首轮变化、完成迭代、训练日志计时 | Organizer 日志的 Accuracy 序列及原项目报告的运行时间；变化为百分点差值 | DataOwner、Organizer、CSP 三方协作；按真实迭代记录逐棵点亮轮次小树 |
| VisualFL | 全局测试准确率、全局测试损失、已完成聚合轮数、参与客户端 | 实验 run 与 data_prepared、round_completed 事件 | 中央全局服务器与各客户端连接，回放逐轮聚合，显示真实样本数 |
| CPU 逻辑回归 | 标签 1 的精确率、召回率、F1、两种预测实现的核对数量 | 固定留出集预测及逐项内积参考实现 | 训练/测试划分条、采样损失游标、混淆矩阵核对；明确非 SGX |
| Kangaroo | 明密文输出核对、输出绝对误差、扩展树节点、进程端到端时间 | 原示例 stdout 与进程墙钟时间 | 明文决策路径与密态推理双通道，最后比较解密输出 |

## 定义与计时范围

- SGBoost 的“较首轮变化”是当前评估准确率减去第一条评估记录，单位为百分点；不是相对于随机模型的提升。日志训练时间与三个进程的端到端时间分别列出。
- VisualFL 的客户端数量与各自样本数来自数据准备事件，当前默认配置为 3 个客户端，每个 40 个训练样本。全局测试集有 30 个样本，默认 5 轮。客户端角色在本机执行，不意味着真实多机部署，也没有接入隐私保护协议。
- VisualFL 的 `duration_ms` 来自最后一条 round_completed 事件，为末轮训练与评估计时；`round_compute_total_ms` 是各轮计时之和。这两项都不包含环境启动与数据准备。事件中的逐轮损失可能变化，图表保留实际序列。
- CPU 对照使用原 Breast 文件固定分成 95 个训练样本、42 个测试样本。矩阵行是真实标签、列是预测标签；精确率为 TP/(TP+FP)，召回率为 TP/(TP+FN)，F1 为 2TP/(2TP+FP+FN)，展示为百分数。分母为零时按 0 处理。损失含初始值及每 60 次更新的采样，一直到第 600 次更新。
- CPU 对照的实现核对只检查向量化预测与逐项内积预测是否相同，不是 SGX 复现或可验证计算证明。训练耗时、留出集推理耗时及测试准确率在结果详情中单独列出。
- Kangaroo 目前只运行单个示例查询；输出一致不能表述为分类准确率。节点总数、虚拟节点数与明文路径均取自原 C++ 日志，绝对误差由两路输出计算。明文路径仅用于解释原示例，不表示密态协议泄露该路径。
- Kangaroo 的端到端时间包含进程初始化、密钥和模型处理；原日志的 Plaintext Running Time 是明文基线局部计时。二者不构成等口径的速度对比，不生成加速比。未测量通信字节数、真实网络时延或 SGX 性能。

## 维护入口

- `portal/assets/project-demos.js`：项目指标定义、各自的演示布局、真实曲线与回放帧。
- `portal/assets/presentation.js`：播放控制；帧数来自该项目的实际迭代/轮次记录。
- `portal/assets/lab.js`：项目导航、环境检测、启动实验、更新结果。
- `adapters/experiments.py`：运行 SGBoost、Kangaroo、VisualFL，解析与持久化指标。
- `adapters/logistic_baseline.py`：CPU 分类统计、损失采样与实现核对。

回放不发起新训练；暂停会停止连线动画。步骤切换保留画布节点，底部控制栏位置固定；减少动态效果设置会关闭动画。小屏幕使用纵向布局。CPU 回放按已到达的真实采样位置逐段展示损失曲线，在进入预测步骤前用“—”保留混淆矩阵的位置，前后切换均不会提前显示最终结果。

## 两种动画视图与速度

每个项目同时保留“实验过程”和“角色交互”。前者使用该项目专属布局，回放实际迭代、轮次或损失采样；后者恢复三角角色关系图，通过编号箭头解释参与方交互。项目概览与回放窗口均可切换视图，结果页的指标定义保持按项目区分。切换视图会暂停，并尽量保留同一讲解阶段。

回放默认 1.75 倍速，可选择 1.5 倍速。步骤间隔分别为 2400ms 和 2800ms；角色虚线、模型传输连线和流水线连线按同一倍率缩短原周期。倍率只影响讲解动画，不改变实验计算、计时或保存的结果。暂停和减少动态效果仍可停止连线动画。

角色视图由 `portal/assets/demo-views.js` 维护；旧图取自认可版提交，保留每个项目的角色与 CPU 非 SGX 标注，步骤切换不重新创建 SVG。


## 本地页面资源更新

入口页为动画相关 CSS/JS 附加版本参数，本地服务对静态资源发送 `Cache-Control: no-store, max-age=0`，并忽略其旧条件缓存。这样更新后不会混用新按钮与旧事件处理脚本。动画视图使用下划线标签，保留鼠标与键盘操作。
